**Deutsch**

Dieses Projekt wurde unter Einsatz von KI-Werkzeugen erstellt. Quellcode, Tests,
PowerShell-Skripte und Dokumentation wurden ueberwiegend mit
[Claude Code](https://claude.ai/code) (Anthropic) erzeugt und vom Maintainer
angeleitet, geprueft, getestet und freigegeben. Commits, an denen die KI
beteiligt war, tragen eine `Co-Authored-By`-Zeile.

  kann aber trotzdem Fehler enthalten. Bitte vor dem Produktiveinsatz selbst
  pruefen - insbesondere die Skripte, die Rechte und Sicherheitsrichtlinien

This project was built with the help of AI tools. Source code, tests,
PowerShell scripts and documentation were largely generated with
[Claude Code](https://claude.ai/code) (Anthropic) and directed, reviewed,
tested and approved by the maintainer. Commits with AI involvement carry a
`Co-Authored-By` trailer.

* The code is covered by unit tests and has been used in practice, but may
